# AI-First Task Manager

## Objetivo

Criar uma API simples para gerenciamento de tarefas.

## Escopo inicial

O sistema deverá permitir:

- criar tarefas;
- consultar tarefas;
- alterar tarefas;
- excluir tarefas.

## Conceito de tarefa

Uma tarefa possui:

- identificador;
- título;
- descrição;
- status;
- prioridade;
- data de criação.

## Status

Uma tarefa poderá estar em um dos seguintes estados:

- TODO
- IN_PROGRESS
- DONE

## Prioridade

Uma tarefa poderá ter uma das seguintes prioridades:

- LOW
- MEDIUM
- HIGH

## Regra importante

O projeto deve permanecer simples.

Não adicionar funcionalidades que não estejam definidas no escopo sem uma decisão explícita.
